========================================================
OBI via n8n — setup notes (paste-ready bits)
========================================================

PREREQUISITE
  n8n must be running with HTTPS on a domain, e.g. https://n8n.emplogent.com
  (n8n Cloud = easiest, or self-host on your VPS with Docker + Caddy/nginx for HTTPS).

--------------------------------------------------------
WORKFLOW (4 nodes):  Webhook -> Code -> HTTP Request -> Respond to Webhook
--------------------------------------------------------

NODE 1 — Webhook
  HTTP Method: POST
  Path: obi
  Respond: "Using 'Respond to Webhook' node"
  Options > Allowed Origins (CORS): https://www.emplogent.com
     (add your *.vercel.app URL too while testing)
  -> Copy the node's PRODUCTION URL (looks like https://n8n.emplogent.com/webhook/obi)

NODE 2 — Code (JavaScript)  [paste this]
------------------------------------------------------------
const incoming = ($json.body && Array.isArray($json.body.messages)) ? $json.body.messages : [];
const messages = incoming
  .filter(m => m && (m.role === 'user' || m.role === 'assistant') && typeof m.content === 'string')
  .slice(-8)
  .map(m => ({ role: m.role, content: String(m.content).slice(0, 1000) }));

return [{ json: {

NODE 3 — HTTP Request  (calls OpenAI)
  Method: POST
  URL: https://api.openai.com/v1/chat/completions
  Authentication: Generic Credential > Header Auth
       Name:  Authorization
       Value: Bearer YOUR_OPENAI_KEY        (stored in n8n credentials, NOT in the URL)
  Send Headers: Content-Type = application/json
  Send Body: JSON
  Body (expression):  {{ $json }}

NODE 4 — Respond to Webhook
  Respond With: JSON
  Response Body (expression):  {{ { "reply": $json.choices[0].message.content } }}
  (If your n8n version didn't set CORS via the Webhook node, add a response header:
     Access-Control-Allow-Origin: https://www.emplogent.com )

Connect: Webhook -> Code -> HTTP Request -> Respond to Webhook.  ACTIVATE the workflow.

--------------------------------------------------------
SECURITY / COST
--------------------------------------------------------
- API key lives in n8n credentials (server-side) — never in the website. Good.
- CORS (Allowed Origins) limits browser calls to your site.
- Rate limiting: n8n has none built in. Put Cloudflare (free) in front of the VPS
  and add a rate-limit rule on /webhook/obi (or nginx limit_req). The webhook URL
  is public, so this matters for cost control.
- Set a monthly usage limit in the OpenAI dashboard (hard cost cap).
- Message length/turn caps are already handled in the Code node.
